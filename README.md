# LLPM — 持ち上げて下ろすと進む機構の物理シミュレーション

**脚を動かすモーターがないのに、なぜロボットは前進するのか？**

LLPM（Lift-Lower-Propel Mechanism）は、100円ショップのロボット玩具などに使われている、胴体を持ち上げて下ろすだけで前進する機構です。

脚は自由に回転する関節で取り付けられており、脚そのものを動かすモーターはありません。重力による脚の振れ、関節の角度制限、地面との摩擦によって前進します。

このプロジェクトでは、その仕組みを2次元・3次元の物理シミュレーションで検討し、さらに1個のサーボモーターで4脚ロボットを歩行・旋回させる可能性を探っています。

## 🔍 何を調べているのか

このシミュレーションでは、ロボットが前進するようにプログラムしているわけではありません。

- 胴体を水平方向に動かす命令は与えない
- 脚の動きを決まった軌道で制御しない
- 人工的な推進力を加えない

入力するのは、胴体の上下動またはねじり動作だけです。

その結果として、重力・摩擦・関節・接地の相互作用から前進や後退が自然に生じるかを検証しています。

## 📊 これまでの主な結果

| モデル | 得られた結果 |
|---|---|
| 1本脚・2次元 | 約13.7 cm/周期の前進 |
| 4本脚・2次元 | 約7〜9 cm/周期の前進 |
| 4本脚・3次元 | 約5.1 cm/周期の直進 |
| 4本脚・3次元 | ねじり指令の非対称化による左右旋回 |

摩擦をゼロにすると前進がほぼ消失し、運動周期によっては後退することも確認しました。

これらは特定のシミュレーション条件で得られた結果であり、実機での再現性は今後の検証課題です。

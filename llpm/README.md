# LLPM 2次元物理シミュレーター

100均ロボなどに使われる **LLPM（Lift-Lower-Propel Mechanism：持ち上げて下ろすと進む機構）** を、2次元の剛体物理で再現して調べるためのブラウザアプリです。

脚の動きや前進を、あらかじめ決めた軌道やアニメーションで与えることはしません。重力、接触、摩擦、関節拘束、上下方向の駆動だけを入力にして、「前進するかどうか」を物理計算の結果として確かめます。

## 内容

| ファイル | 内容 |
|---|---|
| `llpm1.html` | 1本脚モデル。胴体を上下に駆動して、脚が前進を生むかを調べる |
| `llpm4.html` | 4本脚モデル。胴体のねじりで、はす向かいの脚のペアを交互に上げ下げする |

どちらも単一のHTMLファイルで、サーバーやビルドは不要です。

## 使い方

1. ファイルをダウンロードして、ブラウザで開きます（PC向け）。
2. 「▶ 開始」で実験が始まります。スライダーを動かすと、自動でリセットして同じ条件から再実験します。
3. 画面下部の「検証実験」で、条件を振った結果を表で比べられます。

物理エンジン（planck.js）をCDN（jsDelivr）から読み込むため、**インターネット接続が必要**です。オフラインで使う場合は、`planck.min.js` を手元に置いて `<script>` のURLを書き換えてください。

## 使っている技術

- [planck.js](https://github.com/piqnt/planck.js) 1.4.3（Box2Dの JavaScript 移植版）
- 単位は 1 dm = 10 cm、重力は 9.8 m/s² 相当（98 dm/s²）
- 時間刻みは既定で 1/240 s。4脚版は 1/960 s 以上の細かさを推奨（下記「4本脚モデル」参照）

## 1本脚モデル（`llpm1.html`）

### モデル

- **胴体**: 回転自由度を拘束し、水平方向は自由。駆動は胴体重心への鉛直方向の力のみ（PD制御、力の上限あり）
- **脚**: 一様な棒＋おもりで構成。重心と慣性モーメントは質点系の公式で計算
- **股関節**: 角度制限付きの回転関節（ストッパーは剛体拘束）。モーターはなく、脚は重力と接触力で動く
- **地面**: 水平な固定剛体。摩擦はクーロンモデル

### 主な機能

- 自動 / 手動 / 単発の上下動、一時停止、コマ送り、スロー再生、リセット
- 水平移動距離、1周期あたりの移動、脚の角度、接地状態、股関節の制限トルク、股関節が胴体に及ぼす水平力などのリアルタイム計測とグラフ
- 1周期ごとの内訳表（脚が開く間 / 閉じる間 / 空中の移動）とイベントログ（接地、離地、ストッパー衝突）
- 検証実験: 摩擦ゼロ、水平粘性抵抗、脚のおもり位置、脚の長さ、振幅、ストッパー下限角、回転抵抗、周期、持ち上げ時間の割合、時間刻み

### 初期値の想定

全体で約180 g（胴体150 g＋脚30 g）、胴体23 × 8 cm（ティッシュボックス程度）、脚10 cm、摩擦係数0.6。実物の寸法ではなく目安です。

### 確認できたこと（初期設定）

- 水平粘性抵抗0でも、約13.7 cm/周期で前進する
- 摩擦ゼロではほぼ前進しない（0.00 cm）
- 周期を長くすると後退する（周期3 sで約 −14 cm/周期）。持ち上げ中も脚先が接地したまま脚が閉じて、胴体を引き戻すためと考えられる
- 脚とストッパーの向きを左右反転すると、同じ距離だけ逆に進む（向きは条件の設定ではなく、機構の非対称性で決まる）。※この項目は `llpm1.html` の検証実験にはなく、アプリの画面では再現できません

## 4本脚モデル（`llpm4.html`）

### モデル

- 横から見た2次元モデル。前脚2本・後脚2本を、はす向かいのペアA（前左・後右）・ペアB（前右・後左）に分ける。左右の脚は同じ位置に重なる
- ねじりは「股関節の取り付け位置が胴体に対して上下する入力」として扱う。モーターは1個で、前部と後部を前後軸まわりに相対的にねじる想定。前部と後部は同じ大きさで逆向きに回る（配分は1:1に固定、**実機では接触と釣り合いで決まるため、この1:1は仮定**）
  - 上下量 = 左右の脚の間隔 ÷ 2 × sin（ねじり角 ÷ 2）
  - ねじり角は時間とともに正弦的に往復する。ペアAとペアBは逆向きに上下する（**位相差は設定できません**）
  - 駆動は鉛直のみ（角度制御、力の上限あり）。水平方向は駆動しない
- 胴体の水平位置と傾き（ピッチ）は自由。各脚は角度制限付きの受動関節（ストッパーは剛体拘束）で、脚先の摩擦だけで地面と作用する
- 胴体重心の前後位置、前脚÷後脚の長さ比、前後の脚の位置などを変更できる。前後の脚の長さが違うときは、脚先が地面付近から始まるよう初期角度を自動調整する
- 時間刻みは画面から 1/240・1/480・1/960 s を選べる

### 「安定歩行の設定を適用」ボタン

探索で見つけた組み合わせを、ワンクリックで適用します（時間刻みは 1/960 s に切り替わります）。

| 項目 | 値 |
|---|---|
| 胴体の長さ・高さ・質量 | 20 cm・8 cm・120 g |
| ストッパー角（前側・後ろ側） | −2°・26° |
| 脚の初期角度 | 26° |
| 後脚の長さ | 10.5 cm |
| 前脚÷後脚 | 1.1 |
| 脚（棒）の質量 / おもり | 4 g / 0 g |
| 胴体重心位置 | −4.6 cm（後ろ寄り） |
| ねじり角 / 周期 | 10° / 1.25 s |
| 左右の脚の間隔 | 9.5 cm |
| 前後の脚の位置 | 胴体長さの0.39 |
| 摩擦係数 | 0.5（竹の脚先の目安） |

全体で約180 g（胴体120 g＋脚4本48 g＋関節部8 g）の想定です。

### 確認結果（上のボタンの設定、10周期、1周期目を除く平均）

| 条件 | 前進量 | 10周期後の胴体の傾き |
|---|---|---|
| 時間刻み 1/960 s | 約7.2 cm/周期 | 約2.7° |
| 時間刻み 1/480 s | 約7.5 cm/周期 | 約2.5° |
| 時間刻み 1/1920 s | 約7.9 cm/周期 | 約4.4° |
| 時間刻み 1/3840 s | 約7.7 cm/周期 | 約4.6° |
| 時間刻み 1/240 s | 転倒（傾き約90°） | — |
| 摩擦ゼロ | 約0 cm/周期 | 約0° |

- 1/480 s 以下の刻みでは、前進量は約7.2〜7.9 cm/周期の範囲に収まる。ただし傾きは刻みによって変わるため、1/960 s 以上の細かさを推奨する。1/240 s では転倒して結果が成り立たない
- **向きの反転**: 左右の対称性を保って反転すると（ストッパー角の反転に加えて、胴体重心位置と前後の脚の長さも反転）、1/960 s で約 −6.8 cm/周期と、向きが逆になる。ストッパー角だけを反転する画面の「左右反転」実験では、胴体の非対称性が残るため転倒して正しい比較にならない
- **条件を振った結果**（他は上の設定のまま、1/960 s）:
  - 摩擦係数 0.3 → 約8.7、0.4 → 約8.1、0.6 → 約4.7、0.7 → 約6.9 cm/周期（摩擦が大きいほど速いとは限らない）
  - 周期 0.9 s → 約5.9、1.4 s → 約8.1 cm/周期
  - ねじり角 6° → 約4.4 cm/周期
  - 脚の初期角度 0°〜26° → 約6.7〜7.6 cm/周期（影響は小さい）

## 限界と注意

- 2次元モデルのため、左右の傾き（ロール）や横方向の安定は扱いません。4本脚の結果が3次元でも成り立つとは限りません。
- 摩擦はBox2Dの標準クーロンモデル（静止・動摩擦の区別なし）、接触は点接触の近似です。
- 水平粘性抵抗は既定で0です。抵抗0では、空中で得た速度のまま滑り続けます。
- 4本脚モデルは、胴体が大きく傾く不安定な設定では、時間刻みによって結果が大きく変わります。数値は目安として扱ってください。
- 4本脚のねじりの前後配分（1:1）は仮定です。
- 寸法、質量、ストッパー角などの初期値は見積もりで、特定の実機の測定値ではありません。

物理計算部分は、ブラウザなしでNode.js上でも動かせます（`npm i planck@1.4.3`）。パラメーター探索や時間刻みの収束確認は、この方法で行いました。
